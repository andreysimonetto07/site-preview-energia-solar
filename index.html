Perguntas frequentes

Compra grande pede resposta clara.

Quanto posso economizar?

Não existe um percentual universal. A análise depende de consumo, projeto, geração estimada, tarifas e outras condições reais.

Serve para empresa e propriedade rural?

Sim, desde que o projeto seja dimensionado para o perfil de consumo e o local.

Como funciona a simulação?

O site coleta informações iniciais para a equipe preparar uma análise mais adequada.

O orçamento pode ser pelo WhatsApp?

Sim. O formulário prepara uma mensagem organizada para o time comercial.

Quer entender se solar faz sentido para você?

Comece com uma análise simples do seu consumo e do tipo de imóvel.
